# トッフィーのITPクエスト

ドット絵ハムスターのトッフィーと一緒に、TOEFL ITP（Level 1）を得点効率の高い順に攻略するレトロRPG風の学習アプリです。

- 文法 → 語彙 → リスニング Part A → 長文・講義 の順に進む全20ワールド
- オリジナル問題 280問（空所補充・誤り指摘・同義語・ペアマッチ・長文・リスニング）
- ホーム画面に追加すると、オフラインでも遊べます（PWA）
